# Security Policy

## Reporting a vulnerability

Please do not publish exploitable security details, credentials, account information, or real financial messages in a public issue.

Report suspected vulnerabilities privately to the repository owner through GitHub's private vulnerability reporting feature if it is enabled for this repository. If private reporting is unavailable, contact the owner through their GitHub profile and share only the minimum information necessary to establish contact.

## Sensitive data

- Do not include real bank account numbers, bank messages, transaction records, authentication tokens, or signing keys in reports.
- Use synthetic messages and fake identifiers when reproducing parsing issues.
- If a signing key or credential is accidentally exposed, revoke or rotate it immediately where applicable.
