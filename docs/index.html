01 / What it does

Less guesswork.
More clarity.

Spendo AI is being built around the fundamentals of personal finance: reliable transaction records, useful spending summaries, and budgets you can understand.

01 — TRANSACTIONS

Track activity

Review transactions in a searchable ledger, add entries manually, and filter by transaction type.

02 — BUDGETS

Plan your spending

Organize spending, review monthly budgets, and understand your available spending allowance.

03 — NOTIFICATIONS

Reduce manual work

With permission, detect supported payment notifications locally and review uncertain transaction matches.

04 — INSIGHTS

Spot patterns

Use spending summaries and category views to see where money is going over time.

05 — EXPORT

Keep your records

Export a structured transaction ledger for your own records and offline analysis.

06 — IN DEVELOPMENT

AI-assisted finance

The broader Spendo AI vision includes more helpful, natural-language ways to explore personal finances. Availability depends on future implementation.

03 / Privacy first

Your finances are personal.

The current Android build is designed around local Room storage and user-controlled notification access. It does not request SMS-reading permissions in its current manifest, and its manifest does not declare internet access. Cloud sync and remote AI features should not be assumed to be available in this build. Review permissions and source code before installation.
